# HR-Employee-Attrition-Analysis
HR Employee Attrition Analysis using Microsoft Excel

## 📊 Dashboard Preview

![HR Employee Attrition Dashboard](HR%20analytics%20project.png)
## 🎯 Project Objective

To analyze employee attrition patterns and identify key HR factors associated with employee turnover using Microsoft Excel.

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Excel Formulas
- Charts & Data Visualization
- HR Analytics

## 📊 Key Analysis

- Employee attrition by department
- Attrition by job role
- Employee demographics
- Factors related to employee turnover
- HR trends and patterns

## 💡 Key Insights

The analysis helps identify patterns in employee attrition and provides data-driven insights that can support HR decision-making.
